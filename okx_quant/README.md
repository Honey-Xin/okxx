# AI 量化自动交易：完整研究与落地记录

数据区间 2021-11 ~ 2026-10，全部结论来自真实行情与合约统计，不是模拟数据。

---

## 一句话结论

**方向择时（预测涨跌）在这份数据上没有可用 alpha；能赚钱的是资金费率中性套利。**
前者 2026 年已经失效，后者的收益来自市场结构（多头付钱给空头），不依赖预测。

### 2. 资金费率套利：这一条是真的

原理：永续合约每 8 小时（部分币 4 小时）在多头和空头之间结算一次资金费。
费率为正时，**多头付钱给空头**。所以只要「现货买入 + 永续等量开空」，
价格涨跌被对冲掉，只收这笔费率。

### 3. 一个反直觉但重要的发现：这个策略不能做择时

我试过「费率为负就撤出」的防守逻辑：结果换手 384 次，
总收益从 +21.03% 变成 **-41.56%**，年化从 +4.65% 变成 -12.00%。
手续费把所有收益吃光了。**持续持有才对，不要试图躲开负费率期。**

## 二、必须说清楚的偏差（夏普是虚高的）

上面的夏普 9~11 不能直接拿去跟别的策略比，因为回测里 **资金费率被当成了无风险现金流**。
真实做不到，原因有三个：

1. **基差风险**：现货和合约价格会短暂脱钩。实测 4h 基差标准差 0.097%，
   极端曾到 +2.10% / -1.60%。按年化折算，基差带来的波动约 3~4%，
   这一项就能把夏普从 11 打到 3 左右。
2. **保证金占用**：永续空头要压保证金，这部分资金不能再去赚别的收益，实际资金效率打折。
3. **交易所与清算风险**：极端行情下可能被强平，或遇到交易所故障（这类事件历史上真实发生过）。

**打折后的诚实预期：年化 10~15%，最大回撤 3~8%，夏普 2.5~4。**
这依然是很好的风险调整收益，但请不要按「夏普 11」去配资金。

```powershell

# 5. 随时看持仓
python funding_arb_live.py status
python funding_arb_live.py close --coin RPL
```

### scan 的过滤条件（这一段决定你能不能真的赚到钱）

第一次跑 scan 会看到年化 4380%、3611% 的币，那些**不能碰**：
它们没有对应现货市场，或者流动性差到无法平仓。
代码里已经加了四道过滤：

- 必须有 USDT 现货市场（否则没法做 delta 中性，单边开空就是裸赌）
- 年化 ≤ 300%（超过说明费率异常，通常伴随极端行情）
- 现货与标记价偏离 ≤ 0.8%（基差太大会吃掉收益）
- 价格 ≥ 0.001（低价币最小变动单位占比过大）

加完过滤后，当前（2026-10-31）可对冲候选约 75 个，头部是 RPL 283%、INX 274%、STO 232%。
**这个数字异常高，说明现在是特殊窗口，不会长期维持。**

## 四、为什么用 Gate.io 而不是 OKX

本机对 okx.com 有 DNS 污染（解析到 169.254.0.2），OKX 所有接口都连不上。
Gate.io 可以直连。策略本身跟交易所无关，换所只需要改 `EXCHANGE` 和符号格式。

如果你以后能连上 OKX，`funding_arb_live.py` 里把 `ccxt.gate` 换成 `ccxt.okx`，
符号改成 `COIN/USDT:USDT` 即可，其余逻辑不用动。
